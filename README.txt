MELLOW CUP - FRONTEND MILK TEA SHOP WEBSITE

Files:
- index.html: page structure and content
- style.css: styling and responsive layouts
- script.js: navigation, menu filters, add-to-inquiry buttons, and inquiry form

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.

Notes:
- This is a frontend-only demo. It does not save orders to a database or process payments.
- Submitting the inquiry form opens the visitor's default email app with a prefilled draft.
- Replace hello@mellowcup.example with the shop's real email address before publishing.
- Replace sample menu items, prices, shop details, and branding with the real business information.
